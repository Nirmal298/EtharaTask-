# Employment Management System (EMS)

A modern and responsive Employment Management System dashboard built using React and Tailwind CSS.

This project provides a clean HR management interface with:
- Employee dashboard
- Attendance overview
- Leave management
- Payroll metrics
- Department analytics
- Employee tables
- Request submission forms
- Responsive UI design

---

# Features

## Dashboard
- Employee metrics cards
- Attendance statistics
- Payroll overview
- Leave tracking

## Employee Management
- Employee directory table
- Status indicators
- Department tracking
- Search input UI

## Analytics
- Headcount trend chart
- Department distribution progress bars

## Request Form
- Leave request interface
- Query/document request dropdown
- Date picker
- Message submission area

## UI/UX
- Fully responsive design
- Modern Tailwind styling
- Hover animations
- Interactive buttons
- Clean dashboard layout
